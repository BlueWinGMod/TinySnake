TinySnake is an ultra minimalist Android Snake game designed with a single goal : achieving the absolute smallest file size while keeping broad cross-device compatibility ! 

From legacy devices like the  HTC Magic (Android 1.5) to modern flagship hardware, the game dynamically scales its rendering grid to fit any screen resolution and aspect ratio perfectly, even works on the old chat phones like Samsung chacha, it works from Android 1.5 to 17 !
Here is the features

Ultra Lightweight: Entire game logic fits inside a single `MainActivity.java` file (~1.8 KB something source code)
Also adaptive grid : Dynamically calculates screen ratios to render a proportional terrain on any display.
There is also a perfect touch controls, originally the controls would not work but I fixed,
Basic: It's like the old snake game on the nokia, there is very basic things
Score: there is a score on top
I added walls on the 1.0 version so it's more difficult 
Here is the specs requirements (I mean everything works for this) :
No AI included !
No ads
Nothing, just basic gaming 

You need at least android 1.5
At least 10kb of storage (the apk is 9kb)
A touch screen (phones like the htc dream can't play this game)
and that's it
